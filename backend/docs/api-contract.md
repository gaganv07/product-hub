# ProductHub – Shared REST API Contract & Specification

**Document Version:** 1.0.0  
**Authors:** Deviprasad (Frontend Lead) & Gagan Gowda (Backend Lead)  
**Standard Format:** JSON (RESTful Architecture)  
**Base URL:** `http://localhost:5000` (Local) / `http://<EC2-PUBLIC-IP>` (Production)

This document establishes the binding API contract between the frontend client and the backend Express/MongoDB server. Both developers must adhere strictly to these schemas, parameter names, and HTTP status codes.

---

## 1. Global Product Document Schema

Every product document stored in MongoDB Atlas and exchanged between backend and frontend adheres to the following BSON/JSON schema:

```json
{
  "_id": "672c0a91f582ba9842a19e01",
  "productId": "P1001",
  "name": "Dell Inspiron 15 3520",
  "brand": "Dell",
  "category": "Laptops",
  "price": 54990,
  "description": "Powerful daily business and coding laptop with high refresh rate display.",
  "image": "https://images.unsplash.com/photo-1593642632823-8f785ba67e45?w=600",
  "specifications": {
    "ram": "16GB DDR4",
    "storage": "512GB NVMe SSD",
    "processor": "Intel Core i5-1235U 12th Gen"
  },
  "stock": 25,
  "createdAt": "2026-11-06T10:30:00.000Z",
  "updatedAt": "2026-11-06T10:30:00.000Z",
  "__v": 0
}
```

### Field Constraints & Validation Rules

| Field Name | Type | Required | Constraints / Validation | Description |
| :--- | :---: | :---: | :--- | :--- |
| `_id` | String | Auto | MongoDB 24-character hexadecimal ObjectId | Unique primary key generated by MongoDB. |
| `productId` | String | **Yes** | Pattern: `/^[A-Za-z0-9_-]+$/`, Unique, Uppercase | Business SKU code (e.g. `P1001`). Spaces/special characters forbidden. |
| `name` | String | **Yes** | Min length: 2 characters, Trimmed | Full commercial title. |
| `brand` | String | **Yes** | Non-empty string, Trimmed | Manufacturer name (e.g. `Dell`, `Apple`). |
| `category` | String | **Yes** | Non-empty string, Trimmed | Category classification (e.g. `Laptops`, `Smartphones`). |
| `price` | Number | **Yes** | Number $\ge 0$ | Selling price in Indian Rupees (₹). Negative values rejected. |
| `description` | String | No | Default: `""`, Trimmed | Detailed product description. |
| `image` | String | No | Default placeholder URL | HTTPS URL to product photograph. |
| `specifications`| Object | No | Nested subdocument `{ ram, storage, processor }` | Embedded hardware technical specifications. |
| `specifications.ram` | String | No | Default: `"N/A"`, Trimmed | RAM capacity and type. |
| `specifications.storage` | String | No | Default: `"N/A"`, Trimmed | Storage capacity and interface. |
| `specifications.processor` | String | No | Default: `"N/A"`, Trimmed | CPU / Chipset model. |
| `stock` | Number | **Yes** | Integer $\ge 0$, Default: `0` | Available warehouse inventory count. |
| `createdAt` | String | Auto | ISO 8601 Timestamp | Document creation timestamp. |
| `updatedAt` | String | Auto | ISO 8601 Timestamp | Document last modified timestamp. |

## 3. API Endpoints Specification

### 3.1. `GET /api/products` – Retrieve Products Catalogue
* **Method:** `GET`
* **Purpose:** Fetches catalogue products with pagination, category/brand filtering, and price/name sorting.
* **Query Parameters:**
  * `page` (optional, default: `1`): Current page number.
  * `limit` (optional, default: `12`): Number of items per page.
  * `category` (optional, default: `"All"`): Filter by product category.
  * `brand` (optional, default: `"All"`): Filter by brand.
  * `minPrice` (optional): Minimum price filter.
  * `maxPrice` (optional): Maximum price filter.
  * `sort` (optional): Sorting order (`newest`, `price-asc`, `price-desc`, `name-asc`, `name-desc`, `oldest`).
* **Success Response (HTTP 200 OK):**
```json
{
  "success": true,
  "count": 12,
  "total": 24,
  "totalPages": 2,
  "currentPage": 1,
  "categories": ["Accessories", "Electronics", "Home Appliances", "Laptops", "Smartphones"],
  "brands": ["Apple", "Dell", "Dyson", "Google", "Keychron", "Lenovo", "Logitech", "Philips", "Samsung", "Sony"],
  "data": [
    {
      "_id": "672c0a91f582ba9842a19e01",
      "productId": "P1001",
      "name": "Dell Inspiron 15 3520",
      "brand": "Dell",
      "category": "Laptops",
      "price": 54990,
      "stock": 25,
      "image": "https://images.unsplash.com/...",
      "specifications": {
        "ram": "16GB DDR4",
        "storage": "512GB NVMe SSD",
        "processor": "Intel Core i5-1235U 12th Gen"
      }
    }
  ]
}
```

### 3.2. `GET /api/products/:id` – Retrieve Single Product
* **Method:** `GET`
* **Path Parameter:**
  * `id`: MongoDB hexadecimal `_id` (e.g. `672c0a91f582ba9842a19e01`) OR custom `productId` (e.g. `P1001`).
* **Success Response (HTTP 200 OK):**
```json
{
  "success": true,
  "data": {
    "_id": "672c0a91f582ba9842a19e01",
    "productId": "P1001",
    "name": "Dell Inspiron 15 3520",
    "brand": "Dell",
    "category": "Laptops",
    "price": 54990,
    "description": "Powerful daily business and coding laptop.",
    "image": "https://images.unsplash.com/...",
    "specifications": {
      "ram": "16GB DDR4",
      "storage": "512GB NVMe SSD",
      "processor": "Intel Core i5-1235U 12th Gen"
    },
    "stock": 25,
    "createdAt": "2026-11-06T10:30:00.000Z",
    "updatedAt": "2026-11-06T10:30:00.000Z"
  }
}
```
* **Error Response (HTTP 404 Not Found):**
```json
{
  "success": false,
  "message": "Product with ID 'P9999' was not found.",
  "error": "Not Found"
}
```

### 3.3. `GET /api/products/search?q=` – Search Products
* **Method:** `GET`
* **Query Parameter:**
  * `q`: Search keyword (searches across `productId`, `name`, `brand`, `category`, `description`, `specifications.processor`).
* **Security Feature:** Auto-escapes regex characters (`(`, `)`, `+`, `[`, `]`, `*`) to prevent server crashes.
* **Success Response (HTTP 200 OK):**
```json
{
  "success": true,
  "query": "MacBook",
  "count": 1,
  "data": [
    {
      "_id": "672c0a91f582ba9842a19e02",
      "productId": "P1002",
      "name": "Apple MacBook Air M2",
      "brand": "Apple",
      "category": "Laptops",
      "price": 99900,
      "stock": 18
    }
  ]
}
```

### 3.4. `POST /api/products` – Create New Product Document
* **Method:** `POST`
* **Headers:** `Content-Type: application/json`
* **Request Body:**
```json
{
  "productId": "P1015",
  "name": "Asus ROG Zephyrus G14",
  "brand": "Asus",
  "category": "Laptops",
  "price": 149999,
  "description": "Ultraportable gaming laptop with OLED display.",
  "image": "https://images.unsplash.com/photo-1593642632823-8f785ba67e45?w=600",
  "specifications": {
    "ram": "32GB DDR5",
    "storage": "1TB NVMe SSD",
    "processor": "AMD Ryzen 9 8945HS"
  },
  "stock": 12
}
```
* **Success Response (HTTP 201 Created):**
```json
{
  "success": true,
  "message": "Product 'Asus ROG Zephyrus G14' (P1015) added successfully.",
  "data": {
    "_id": "672c10a4e839bb0011a01234",
    "productId": "P1015",
    "name": "Asus ROG Zephyrus G14",
    "brand": "Asus",
    "category": "Laptops",
    "price": 149999,
    "description": "Ultraportable gaming laptop with OLED display.",
    "image": "https://images.unsplash.com/...",
    "specifications": {
      "ram": "32GB DDR5",
      "storage": "1TB NVMe SSD",
      "processor": "AMD Ryzen 9 8945HS"
    },
    "stock": 12,
    "createdAt": "2026-11-07T04:30:00.000Z",
    "updatedAt": "2026-11-07T04:30:00.000Z"
  }
}
```
* **Error Response – Missing Required Fields (HTTP 400 Bad Request):**
```json
{
  "success": false,
  "message": "Please provide all mandatory fields: productId, name, brand, category, and price.",
  "error": "Missing Required Fields"
}
```
* **Error Response – Duplicate Product ID (HTTP 409 Conflict):**
```json
{
  "success": false,
  "message": "Product ID 'P1015' already exists in database. Please use a unique Product ID.",
  "error": "Duplicate Product ID"
}
```
* **Error Response – Negative Price (HTTP 400 Bad Request):**
```json
{
  "success": false,
  "message": "Price must be a valid positive number or zero.",
  "error": "Invalid Price"
}
```

### 3.5. `PUT /api/products/:id` – Update Existing Product
* **Method:** `PUT`
* **Path Parameter:** `id` (`productId` or `_id`)
* **Headers:** `Content-Type: application/json`
* **Request Body:** Partial or full product fields to modify.
```json
{
  "price": 139999,
  "stock": 15,
  "specifications": {
    "ram": "32GB DDR5",
    "storage": "2TB NVMe SSD",
    "processor": "AMD Ryzen 9 8945HS"
  }
}
```
* **Success Response (HTTP 200 OK):**
```json
{
  "success": true,
  "message": "Product 'Asus ROG Zephyrus G14' updated successfully.",
  "data": { ... }
}
```
* **Error Response (HTTP 404 Not Found):**
```json
{
  "success": false,
  "message": "Cannot update. Product with ID 'P9999' was not found.",
  "error": "Not Found"
}
```

---

### 3.6. `DELETE /api/products/:id` – Delete Product Document
* **Method:** `DELETE`
* **Path Parameter:** `id` (`productId` or `_id`)
* **Success Response (HTTP 200 OK):**
```json
{
  "success": true,
  "message": "Product 'Asus ROG Zephyrus G14' (P1015) was deleted successfully from MongoDB.",
  "deletedId": "672c10a4e839bb0011a01234",
  "productId": "P1015"
}
```
* **Error Response (HTTP 404 Not Found):**
```json
{
  "success": false,
  "message": "Cannot delete. Product with ID 'P9999' was not found.",
  "error": "Not Found"
}
```
